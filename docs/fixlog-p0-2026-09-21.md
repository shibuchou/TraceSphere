## P0-1 平台数据缺口修复

| 缺口 | 根因 | 修复 | 验证 |
|---|---|---|---|
| 容器资源无 `vm_id` | ingest 惰性建容器时未落 `vm_uuid` | `_ensure_container` 读取 `attributes.vm_uuid` → `vm_id` + `VM --contains--> Container` 边 | 6/6 在线容器有 vm_id + contains 边 |
| 容器名是哈希占位 | 短 ID 占位且真实名被覆盖 | 真实名（`attributes.name`）优先，仅新建且无名时回退短 ID | 6 个容器显示 docker 真名（agent-service 等） |
| evidence 无 `value/delta` | correlate 未提升 payload 数值字段 | `_evidence_for` 提升 `value/delta/unit` 到证据顶层 + description | 探针事件 value=1/delta=1 可见 |
| `/context` `window.seconds=0` | 响应未回填 | 由 from/to 计算 `seconds` | 响应 window.seconds=960 |

## P0-2 直报上线（下线临时 event-bridge）

- **vm-agent（Go）**：
  - 新增 `reporter.go`：批量 POST `/api/v1/events`（2s 冲刷 / 128 条成批；本地 stdout 始终保留）
  - 新增 `journal_oom.go`：内核 OOM 轮询（`journalctl -k` → `memory.events.oom_kill`，含容器归属/被杀进程/精确时间）
  - eBPF 事件映射：`oom.ebpf` / `tcp.retransmit`（exec/exit 默认不上报）；PSI 指标 `cgroup.metric`（`resource_id=vm:*`）
  - 环境：`VMAGENT_PLATFORM_URL / VMAGENT_VM_UUID / VMAGENT_TOKEN / VMAGENT_REPORT_PROCESS`（`/etc/tracesphere/agent.env`）
- **agent-service（Python）**：
  - AppEvent 直报 + 启动时 Agent 注册；`container_id`（HOSTNAME 短 ID）+ `vm_uuid` 注入
  - 配置：`EVENTS_URL` / `VM_UUID`（docker-compose.yml）
- **平台 ingest**：短容器 ID（12 位）按前缀归一到完整 64 位 ID；应用层归因优先 container/service/task（修复 AppEvent 上卷到 VM 的问题）
- **event-bridge**：已停用并标记 legacy（保留作无直报环境的应急回退）；`demo-up.sh` / `acceptance.sh` / `case1-oom-real.sh` 已去除桥逻辑
- **验证**：任务事件 → `container:<id>` + `runs_on` 边；内核 OOM 事件（source=kernel）直报入库；桥确认未运行

## 审计整改轮（2026-09-25：安全基线 + 证据公开 + 工程一致性）

按外部审计（对照赛题 a–g 与约束）逐项整改：

**P0（安全 / 提交材料）**
- 统一 Token：平台 `TRACESPHERE_API_TOKEN`（**非回环绑定未配置即拒绝启动**）；RCA `TRACESPHERE_RCA_TOKEN`（/api/* 除 health 外需 Bearer）；直报链路全部带票（vm-agent `VMAGENT_TOKEN`、agent-service/mock-dcgm `PLATFORM_TOKEN`、RCA 读平台 `TRACESPHERE_PLATFORM_TOKEN`）。
- 限流与暴露面：平台/RCA 写接口每 IP 分钟级限流（默认 600，`*_RATE_LIMIT` 可调）；RCA CORS 改为来源白名单；负载控制面（Prometheus/cAdvisor/llama/Toxiproxy/mock-dcgm/agent `/task`）默认**仅回环绑定**，跨机读取 Prometheus 用 `PROM_BIND`，Agent 任务可选 `TASK_TOKEN`。
- 提交包纳入 `docs/evidence` **脱敏公开副本**；脱敏脚本扩展替换（内网网段 / VM uuid / 口令 / 内网宿主 / 本机用户名）。
- 仓库凭据清扫：`deploy/` 42 个运维脚本（密码 → `${ZS_PW:?}`、IP → `${MN_IP:?}` 等占位）与 4 份内部文档（口令/内网宿主 → 占位符）；`demo` 文档同步脱敏并补充 Token 导出说明。

**P1（工程 / 可观测质量）**
- vm-agent：新增 `identity.go`（PID → cgroup → 容器 ID，60s 缓存）并附 `vm_uuid`，内核事件不再孤立；`setupProbes` 改为**逐 hook 降级**（单项失败不拖垮全部）；上报失败落 `spool` 并 30s 重试（上限 200 批）。
- 平台：`ZSVIRT_SYNC_INTERVAL` 周期同步（本环境 120s）——方案文档所述"可配置周期同步"落地。
- 隐私：agent-service 仅上报 `question_len / answer_len / result_len`（不再上传问题/回答/工具结果正文），与 README「不采集业务请求体」一致。
